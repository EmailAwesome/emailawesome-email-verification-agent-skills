# Contributing

Open an issue with the business problem, expected output, installed commit and a synthetic reproduction. Keep each change focused on the existing workflow; avoid duplicate keyword-only skills.

For a pull request, update the skill and relevant example together, run `python3 -m unittest discover -s tests -v`, and describe what was tested. Product assertions need current official evidence. Installation tests, offline examples and authenticated runs are different claims. Never include customer lists, credentials or billing data. Review current destination terms before expanding collection scope.
